The keyboard acts as an **Xbox 360 controller**: each of its 24 controls has two keys. The game
sees the same controller whatever drives it. For the interactive view, open the
**[Garage](../../garage/)**.

## What the badges mean

- <StatusBadge status="tested" /> pinned by ReCarbon's unit tests (`key_map_test`, `settings_keys_test`, `pad_map_test`).
- <StatusBadge status="automated" /> seen in scripted or virtual-controller runs.
- <StatusBadge status="hand-verified" /> checked by a person in a hand test.
- <StatusBadge status="source" /> read from ReCarbon's code or option text, not yet hand-tested.
- <StatusBadge status="pending" /> expected from the option text, waiting for its hand test.
- <StatusBadge status="unverified" /> the control is bound, but what it does in the game isn't known yet: handbrake, nitrous, Speedbreaker, camera and look back are all **to verify**.
- <StatusBadge status="not-mapped" /> ReCarbon doesn't read the input (back paddles, the Guide button).

The **key → control** bindings below are all tested. The **game actions** in a race are pending

## Rebinding keys

These are the **defaults**. To change them:

1. Open Settings (F1, Fn+F1 or Cmd+,) and go to the **Controls** tab (Q / E).
2. Pick a control's row. Left and right choose its first or second key.
3. Press Space (or A) and then the new key. **Backspace** (or Y) clears the slot; **Delete** (or X)
   resets the control to its defaults.

Or edit the `[keys]` table of `settings.toml` (`~/Library/Application Support/ReCarbon/`). Names
are the keys' physical positions, whatever the layout: `"w"`, `"left_shift"`, `"semicolon"`,
`"keypad_1"`, or `"none"`. The second key of a control is `<name>_2`:

```toml
[keys]
right_trigger = "w"
right_trigger_2 = "up"      # a second key for the same control
left_trigger = "s"
left_trigger_2 = "down"
```

F1 opens Settings and can't be bound. Neither can Command, fn or the media keys.

Controller rebinding, separate keyboard and controller profiles, and WASD and Arrows presets are
**planned (M8)**, not available yet.

## Controller notes

- Buttons are mapped **by position**: South, East, West, North are A, B, X, Y, so a PlayStation
  pad's Cross is A.
- Sticks have a radial deadzone (8% by default) and the triggers their own (2%): Settings > Input.
- **View (Back)** is held back for a moment while it might start the View + Menu chord that opens
  Settings.
- **Back paddles and extra buttons** aren't read by ReCarbon. If the pad's own firmware or
  software remaps a paddle to another button, it acts as that button. Whether a given pad's
  paddles reach SDL at all is device-specific and unverified.
